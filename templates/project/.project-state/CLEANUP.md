# Cleanup

Things to remove, archive, or consolidate. Hand-curated; no automatic scanning in V1.

## Stale Files

- Files that look unused — verify before deleting.

## Duplicates

- Pairs/groups that should collapse into one.

## Stale Docs

- Documentation that contradicts current behavior.

## Unused Code

- Dead branches, unreachable helpers.

## Token-Heavy Files

- Large files that get pulled into context frequently. Candidates for splitting or moving out of `Read` reach.

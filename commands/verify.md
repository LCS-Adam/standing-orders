---
description: Run verification checks for the most recently completed task
---

Determine the most recently completed task by:
1. Reading `docs/checkpoint.md` for the last completed step
2. Or scanning phases/ for the most recent COMPLETED task

For that task:
1. Read its Verify section
2. Execute each verification command
3. Compare output against expected results
4. Report PASS/FAIL for each check
5. If all pass, confirm the task is verified
6. If any fail, report the failure and suggest troubleshooting from the task's Troubleshooting section

Update the task file status if verification changes anything.
